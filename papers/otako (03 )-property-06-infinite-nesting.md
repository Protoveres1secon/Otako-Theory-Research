# O-Ta Theory — Property 6: Infinite Nesting

If the O-Ta nesting process continues indefinitely, the laws governing
the O-Ta system remain unchanged.

Only the representative value C changes according to the nesting level.

Therefore, infinite nesting does not create a new governing law at every
level. The O-Ta principle continues to operate regardless of the depth
of nesting.

---

## 2. Representative-Value Sequence

For successive O-Ta levels, the representative values follow a strictly
decreasing order:

a₁ > a₂ > a₃ > ...

Equivalently:

aₙ₊₁ < aₙ

This describes the change in the representative value as the nesting
process continues.

---

## 3. Two-Level O-Ta Structure

Consider two O-Ta structures:

B¹ and B².

B² is nested inside B¹.

When B² is nested into B¹, the bottom of B² does not completely reach
the corresponding position of B¹.

Instead, the bottom of B² is displaced by one interval relative to the
previous position.

---

## 4. Recursive Nesting

The displacement created by one O-Ta nesting becomes the stopping
position for the next O-Ta.

The process can therefore continue:

B¹ → B² → B³ → B⁴ → ...

The same O-Ta rule continues to be applied at each successive level.

---

## 5. Infinite Continuation

When the O-Ta nesting process continues without limit:

B¹ → B² → B³ → ...

the governing O-Ta laws remain unchanged.

The representative values continue to follow:

a₁ > a₂ > a₃ > ...

while C changes according to the nesting level.

---

## 6. Nesting-Offset Principle

At each nesting operation, the bottom of the next O-Ta is displaced by
one additional interval relative to the preceding O-Ta.

This displacement becomes the stopping position for the next nesting
operation.

The process is therefore repeated from one nesting level to the next.

---

## 7. Infinite O-Ta Nesting

Let the nesting continue indefinitely:

B¹ ⊃ B² ⊃ B³ ⊃ ... ⊃ Bⁿ ⊃ ...

The corresponding representative values satisfy:

a₁ > a₂ > a₃ > ... > aₙ > ...

The governing O-Ta law remains unchanged throughout the nesting process.

---

## 8. Summary

Property 6 establishes:

1. O-Ta nesting can continue indefinitely.
2. The governing O-Ta laws remain unchanged.
3. The representative value C changes according to the nesting level.
4. The representative values follow a strictly decreasing order:

   a₁ > a₂ > a₃ > ...

5. The bottom of the next O-Ta is displaced by one additional interval.
6. This displacement becomes the stopping position for the following
   O-Ta.
7. The nesting process can therefore continue recursively:

   B¹ → B² → B³ → ...
