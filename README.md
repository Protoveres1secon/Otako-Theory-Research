# O-Ta-Ko Theory Research

**Official research portal:** https://o-ta-ko-web.web.app/

O-Ta-Ko Theory is an independent, experimental proposed spatial model exploring constrained motion between nested domains. The research portal brings together the theory's terminology, symbols, logical operators, axioms, laws, formulas, grid models, source texts, and an interactive calculator.

The terms **Binh Domain** and **Chum Domain** are defined within O-Ta-Ko Theory and should be read according to the project's own terminology.

## Research status

This project is under experimental development. It has **not yet been peer-reviewed or scientifically validated**. The site preserves source wording so readers can inspect the definitions and provide independent feedback; it should not be presented as an established scientific result.
